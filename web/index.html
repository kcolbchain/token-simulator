  The dashboard runs a simplified, deterministic form of
  token_simulator.model
  in the browser. The Python library is the authoritative implementation — the JS port here exists so you can
  play with parameters without installing anything.
  Monte-Carlo mode (distributional inputs, 10k trajectories, p5/p50/p95) is tracked in
  #1 and will ship as a toggle on this
  dashboard when the library lands it. This model is a consistency checker, not a price predictor —
  if parameters are unreasonable the plots break loudly, which is the point.
